# src/remora/AGENTS.md

The core modules: one expression IR and the contracts that every backend, reader and surface builds on. This file applies inside every subpackage too, and each subpackage's own `AGENTS.md` adds its invariants.

- `expr.py` is the immutable expression IR and a leaf module that imports nothing from remora. `__bool__` raises so `and`/`or`/chained comparisons fail loudly (use `&`/`|`/`~`, and parenthesize comparisons). There is no `Ne` node: `!=` builds `Not(Comparison(EQ, ...))`, which makes Wireshark's multi-value `!=` pitfall unrepresentable. `FieldRef` is deliberately unhashable (`__eq__` returns an `Expr`), so dedup by `.name`.
- `values.py` is the single mapping from tshark ftypes to Python types and parsers. Parse errors raise `ValueError`, and unknown ftypes fall back to `str`. `coerce_literal` normalizes user literals at compile time for every backend. `FT_ABSOLUTE_TIME` accepts every form tshark renders in either reader, and only forms that name one instant: a time with no offset, or a zone abbreviation other than `UTC`, raises (#117; the measured table is in `docs/semantics.md`). Negative epoch seconds are the one form a user literal reads differently: tshark's `-1.500000000` is -1 s + 0.5 s, a literal `"-1.5"` is a signed decimal, so `FTypeInfo.parse_literal` exists and `coerce_literal` uses it. `FT_GUID` is `uuid.UUID` and `FT_EUI64` exactly 8 `bytes` (#69), each read only from the text tshark prints (8-4-4-4-12; colon pairs or 16 hex digits), never from wire bytes; `FTypeInfo.check_literal` makes an EUI-64 `bytes` literal of another length a `ValueError`. `FT_OID`, `FT_UINT_STRING`, `FT_STRINGZPAD` and `FT_AX25` stay `str` by the same decision. An OID is the numeric dotted text tshark prints, so it orders as text; #149 recommends an `OID` value object. `docs/semantics.md` has the measured renderings, and #149's recommendation with its migration.
- `fields.py` is the contract hub. `RawPacket` is the minimal packet protocol: `get_raw(name) -> tuple[str, ...]`, with `()` meaning absent. `Field`/`MultiField` are dual-mode descriptors. Class access returns a `FieldRef[T]`; instance access returns `T | None` (scalar) or `tuple[T, ...]` (multi). Multiplicity lives in the descriptor *class* because `@overload` can only express the return type per class.
- `planner.py` is a pure two-level pushdown that never spawns tshark. Pushable conjuncts become `-Y`, a projection enables `-T fields`, and opaque lambdas force `-T ek`. Conjuncts that fail to push become residual Python predicates. A residual that reads an `FT_OID` field forces `-T ek` too (#149): an OID that prints empty is a reachable value, and `-T fields` reads it as absence when it is the only occurrence.
- `capture.py` is the public pcap-path surface. `Capture` is an immutable builder: `filter()` accumulates terms, and `select()` sets the projection that makes fields mode reachable (#105). Iteration plans, spawns tshark, applies the residual predicate, and closes the subprocess however it ends.
